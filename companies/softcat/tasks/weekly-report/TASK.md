한 주 동안의 작업·비용·블로커를 집계해 한국어 보고서를 남긴다.

## 담을 것

| 항목 | 내용 |
|---|---|
| 완료된 작업 | 무엇이 끝났나 |
| 진행 중 / 막힌 작업 | **막힌 건 원인과 풀 사람을 명시** |
| 비용 | 이번 주 소진액, 에이전트별 분해 |
| 지표 | 리뷰 지적 유효율, 사람 개입 횟수 |

## 형식

**사람이 수정 없이 그대로 쓸 수 있어야 한다.** 그게 완료 기준이다.
초안을 던지고 "검토 부탁드립니다"로 끝내지 마라.

## 하지 말 것

- 좋은 소식만 쓰지 마라. 막힌 것과 실패한 것이 더 중요한 정보다.
- 숫자 없이 "잘 진행 중"이라고 쓰지 마라.
