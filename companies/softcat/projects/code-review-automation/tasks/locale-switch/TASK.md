## 배경 (검증된 사실)

`ui/src/i18n/index.ts`가 언어를 **`lng: DEFAULT_LOCALE`("en")로 고정**한다.
저장소 전체에 `changeLanguage` 호출도, 언어 감지기도, 언어 설정도 없다.

즉 **`ko.json`을 아무리 채워도 화면은 영어 그대로다.**
번역보다 먼저 "한국어로 바뀌는 길"이 있어야 한다. 이 작업이 그것이다.

## 할 일 — 최소 구현

1. 브라우저 언어(`navigator.language`)가 지원 로케일이면 그것을 쓴다.
   지원하지 않으면 `en`으로 떨어진다.
2. 개발·검증용으로 URL 쿼리 `?lng=ko` 로 강제 전환할 수 있게 한다.

**사용자 설정 화면(언어 선택 드롭다운)은 이 작업 범위 밖이다.**
그건 제품 결정이 필요하다. 만들지 마라.

## 제약

- `ui/src/i18n/` 밖은 가능한 한 건드리지 않는다. 업스트림 머지 충돌을 줄이기 위해서다.
- 새 의존성 추가가 필요하면 **추가하기 전에 이유를 작업 댓글에 적고 멈춘다.**
  (예: `i18next-browser-languagedetector`) 직접 구현이 몇 줄이면 그쪽을 택한다.
- 기존 동작(영어 기본)이 바뀌면 안 된다. 영어 브라우저 사용자는 아무 변화가 없어야 한다.

## 검증

```
pnpm --filter @paperclipai/ui typecheck
pnpm test:run ui/src/i18n
```
그리고 실제로 `?lng=ko` 를 붙였을 때 `App.tsx`의 기존 한국어 문구
("첫 회사를 만드세요")가 보이는지 확인한다. **이게 보여야 완료다.**
