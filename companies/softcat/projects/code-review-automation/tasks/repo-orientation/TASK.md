우리 저장소가 어떤 구조이고 어떤 규약을 갖고 있는지 조사해 문서로 남긴다.
이 문서는 **리뷰어가 리뷰할 때 참조할 기준**이 된다.

## 조사할 것

1. **저장소 규약** — `AGENTS.md`, `CONTRIBUTING.md`, `DESIGN.md`, `rules/*.mdc`
   에 적힌 규칙 중 **리뷰에서 실제로 걸러야 할 것**만 추려라.
2. **검증 명령** — 어떤 명령으로 타입체크·테스트·린트를 돌리는가.
3. **자주 깨지는 지점** — 최근 커밋 이력에서 수정 커밋이 반복된 영역을 찾아라.

## 산출물

문서 하나. 리뷰어가 읽고 바로 쓸 수 있는 형태여야 한다.
**확인하지 못한 범위를 반드시 명시할 것.**

## 하지 말 것

- 저장소 전체를 요약하지 마라. 리뷰에 쓰이지 않는 정보는 넣지 마라.
